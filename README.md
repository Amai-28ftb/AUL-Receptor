## なにこれ
カスタムオブジェクトやトラックバーの動作にイージングを適用させる為の Script です。
イージングを共有するだけなので、この Script 自体はイージングを提供しません。他の Script を導入してください。

カスタムオブジェクトなどから直接『.tra2』の挙動を取得できない為、苦肉の策でこうなりました。
オブジェクトの0～totaltimeの範囲を分割サンプリングして疑似的にイージングを再現してます。

## 使い方
1. カスタムオブジェクトとして『EasingReceptor』を呼び出します
2. トラックバーの『軌道適応用』に対して 0→100 でお好みのイージングを掛けます。
3. 軌道番号をお好みの数字に設定します。
4. 別の対応 Script から、今回指定した軌道番号を選びます
5. イージングが適応されます。
